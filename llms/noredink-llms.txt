# NoRedInk

> NoRedInk is a K-12 English Language Arts platform for grammar and writing instruction, offering adaptive practice, authentic assessments, personalized high-interest content, guided essays, peer/self review, and an AI-powered Grading Assistant. Its public API surface is a standards-based OAuth 2.0 / OpenID Connect authorization server used for single sign-on and classroom rostering integrations (Clever, ClassLink, Canvas, Google Classroom).

This file is generated by the API Evangelist enrichment pipeline from the NoRedInk provider profile and the artifacts harvested into this repository. It is not published by NoRedInk.
